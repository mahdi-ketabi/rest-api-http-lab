نکات کلیدی برای توضیح در مصاحبه

REST چیست؟

سبکی برای طراحی API حول منابع (Resources). در این تمرین، /api/products یک منبع است.

تفاوت 200 و 201 و 204

200 یعنی درخواست موفق بوده؛ 201 یعنی منبع جدید ساخته شده؛ 204 یعنی موفق ولی بدون بدنهٔ پاسخ.

Fetch و خطا

Fetch معمولاً برای وضعیت HTTP مثل 404 رد نمی‌شود؛ باید response.ok را بررسی کنی.

اطلاعات ماندگار نیستند

داده‌های POST و PATCH فقط در حافظهٔ سرور هستند و با راه‌اندازی مجدد بازنشانی می‌شوند.
